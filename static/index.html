TWStock Query
免費公開來源 · TWSE / TPEx / FinMind / MOPS

台灣上市櫃公司資訊查詢

輸入股票代號或公司名稱，可指定基準日（as_of）回推當日的 TTM / 年化財務數據。

常用範例：2330 台積電 · 2454 聯發科 · 2317 鴻海 · 2412 中華電 · 6488 環球晶

三大法人買賣超（單日）

單一交易日 x 單一股票的三大法人買賣明細（單位：股）。上市取 TWSE T86、上櫃取 TPEx dailyTrade；資料起始日 2012-05-02。

全市場估值（本益比 / 殖利率 / 股價淨值比）

TWSE 上市股票單一交易日的市值加權估值。分子 / 分母皆由 BWIBBU_d 個股資料反推：EPS=close/PER、BVPS=close/PBR、DPS=close×yield%/100；股數 ≈ paid_in_capital / 10（台股面額慣例，非嚴格流通股本）。

單一公司估值展開（反推 EPS / BVPS / DPS → 估市值）

同一天上游與全市場 endpoint 共用 cache，反推公式完全一致：EPS=close/PER、BVPS=close/PBR、DPS=close×yield%/100；股數 = paid_in_capital / 10。

年報財務分析（MOPS 官方申報 ROE / ROA / EPS + 償債與效率比率）

從 MOPS 公開資訊觀測站「財務分析彙整表 t51sb02」抓取年報官方申報值。上游 payload 以整批市場為粒度，同一年重複查不同股只打上游一次；市場先試上市找不到再試上櫃。
